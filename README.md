# Raju Challa Portfolio — V2

A responsive, cinematic dark-red/black AWS & DevOps portfolio inspired by the provided Instagram Reel's dramatic red lighting, dark background, centered portfolio presentation, and showcase feel. The design is original and adapted to your profile.

## Features
- Responsive desktop/tablet/mobile layout
- Cinematic red/black palette and subtle glow/orbit effects
- Hero profile, About, toolbox, projects, engineering approach, contact
- Project category filters and expandable project details
- Mobile navigation, reveal animations, back-to-top button
- Reduced-motion accessibility preference
- No framework or build step; GitHub Pages ready

## GitHub Pages
1. Create a repository, e.g. `raju-challa-portfolio`.
2. Upload the contents of this folder to the repository root (including `assets/profile.jpeg`).
3. Repository Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Save and wait for deployment.
